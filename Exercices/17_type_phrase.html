Exercices : Les types de phrases

الجُمْلة العَرَبِيَّة
La phrase nominale (مُبْتَدَأ + خَبَر) et la phrase verbale (فِعْل + فَاعِل + مَفْعُول) se distinguent d'abord par le premier mot de la phrase. Ces exercices vous entraînent à les reconnaître, à en analyser les éléments, et à passer de l'une à l'autre.

1Nominale ou verbale ?

Indiquez le type de chaque phrase (N pour nominale, V pour verbale)

  1. البَيْتُ كَبِيرٌ →
  2. ذَهَبَ الوَلَدُ إِلَى المَدْرَسَةِ →
  3. الطَّالِبُ مُجْتَهِدٌ →
  4. يَشْرَبُ الوَلَدُ مَاءً →
  5. هُوَ طَالِبٌ →
  6. فَتَحَ الأُسْتَاذُ الكِتَابَ →
  7. المَدِينَةُ جَمِيلَةٌ →
  8. أَكَلَتِ البِنْتُ تُفَّاحَةً →

2Analysez la phrase nominale

Identifiez le مُبْتَدَأ (sujet) et le خَبَر (information) de chaque phrase

  1. السَّيَّارَةُ سَرِيعَةٌ — مُبْتَدَأ : — خَبَر :
  2. الجَوُّ بَارِدٌ — مُبْتَدَأ : — خَبَر :
  3. مُحَمَّدٌ طَبِيبٌ — مُبْتَدَأ : — خَبَر :
  4. الكِتَابُ هُنَا — مُبْتَدَأ : — خَبَر :

3Analysez la phrase verbale

Identifiez le فِعْل (verbe), le فَاعِل (sujet) et le مَفْعُول (complément) de chaque phrase

  1. كَتَبَ الوَلَدُ رِسَالَةً — فِعْل : — فَاعِل : — مَفْعُول :
  2. تَدْرُسُ الطَّالِبَةُ العَرَبِيَّةَ — فِعْل : — فَاعِل : — مَفْعُول :
  3. فَهِمَ الطَّالِبُ الدَّرْسَ — فِعْل : — فَاعِل : — مَفْعُول :

4Accord sujet/verbe : le piège du pluriel

Complétez chaque phrase verbale avec la forme du verbe correctement accordée (rappel : toujours au singulier quand le sujet suit le verbe)

  1. الرِّجَالُ (travailler, présent — les hommes travaillent)
  2. النِّسَاءُ (rire, présent — les femmes rient)
  3. الطُّلَّابُ الدَّرْسَ (écrire, passé — les étudiants ont écrit la leçon)

5Nominale ↔ verbale : transformez

Transformez chaque phrase nominale en phrase verbale équivalente, ou inversement, en gardant le même sens général

  1. الأُسْتَاذُ يَكْتُبُ الدَّرْسَ (verbale) → transformez en description nominale (ex. « habile ») :
  2. أَنْتَ تَفْهَمُ الدَّرْسَ (verbale) → مُبْتَدَأ + خَبَر équivalent :

6Le sujet implicite

Pour chaque phrase verbale, indiquez quel est le sujet, même s'il n'est pas écrit séparément

  1. كَتَبْتُ رِسَالَةً → sujet :
  2. اُكْتُبْ الدَّرْسَ → sujet :
  3. فَهِمْنَا السُّؤَالَ → sujet :

7Vrai ou faux ?

Indiquez si les affirmations sont vraies (V) ou fausses (F)

  1. Une phrase nominale doit toujours contenir un verbe « être » explicite
  2. Une phrase verbale commence toujours par un verbe
  3. Le مُبْتَدَأ et le خَبَر sont tous les deux au cas sujet (مَرْفُوع)
  4. Dans une phrase verbale, le complément direct est au cas sujet
  5. Le خَبَر peut être un adjectif, un nom, un adverbe de lieu ou un groupe prépositionnel
  6. Le verbe reste toujours au singulier quand le sujet le suit, même si ce sujet est pluriel

8Trouvez l'erreur

Chaque phrase contient une erreur d'accord ou de cas. Corrigez-la

  1. الوَلَدُ صَغِيرَةٌ (accord de genre) →
  2. كَتَبَ الوَلَدُ رِسَالَةٌ (cas du complément direct) →
  3. يَعْمَلُونَ الرِّجَالُ (accord verbe/sujet postposé) →

9Exercice de compréhension

Lisez et répondez

البَيْتُ كَبِيرٌ. يَسْكُنُ فِيهِ الأُسْتَاذُ مَعَ عَائِلَتِهِ. الأُسْتَاذُ مَاهِرٌ فِي التَّدْرِيسِ. كُلَّ يَوْمٍ، يَكْتُبُ الدَّرْسَ عَلَى السَّبُّورَةِ وَيَشْرَحُهُ لِلطُّلَابِ.
