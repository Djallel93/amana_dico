2Accord en genre

Choisissez la forme correcte de l'ordinal

  1. الدَّرْسُ ______ (أَوَّلُ / أُولَى) → La première leçon
  2. الْكِتَابُ ______ (ثَالِثٌ / ثَالِثَةٌ) → Le troisième livre
  3. الصَّفْحَةُ ______ (خَامِسٌ / خَامِسَةٌ) → La cinquième page
  4. الْيَوْمُ ______ (رَابِعٌ / رَابِعَةٌ) → Le quatrième jour
  5. السَّنَةُ ______ (سَادِسٌ / سَادِسَةٌ) → La sixième année
  6. الطَّابِقُ ______ (سَابِعٌ / سَابِعَةٌ) → Le septième étage
  7. الْمَرَّةُ ______ (ثَامِنٌ / ثَامِنَةٌ) → La huitième fois
  8. الصَّفُّ ______ (تَاسِعٌ / تَاسِعَةٌ) → La neuvième classe

8Trouvez l'erreur

  2. الصَّفْحَةُ الثَّالِثُ →
  3. الْكِتَابُ خَامِسٌ (sans article) →

9Vrai ou Faux

Indiquez si les affirmations sont vraies (V) ou fausses (F)

  1. Les ordinaux se placent avant le nom en arabe
  2. Les ordinaux s'accordent en genre avec le nom
  3. أَوَّلُ et أُولَى suivent un schème régulier
  4. Si le nom a l'article الـ, l'ordinal doit aussi l'avoir
  5. Les ordinaux 3-10 suivent le schème فَاعِل
  6. Pour 11-19, on utilise l'ordinal de l'unité + عَشَرَ/عَشْرَةَ
  7. Les dizaines utilisent la même forme que les cardinaux
