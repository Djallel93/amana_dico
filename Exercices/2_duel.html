تَمَارِين المُثَنّى
👋 Instructions : Complétez les exercices suivants pour pratiquer le duel en arabe. Rappelez-vous : le duel est utilisé uniquement pour DEUX choses/personnes. Ajoutez ـانِ (nominatif) ou ـَيْنِ (accusatif/génitif) !

1Formation du duel : cas nominatif

Transformez les mots suivants au duel (cas sujet - nominatif)

Rappel : Ajoutez ـانِ à la fin du mot

  1. كِتَابٌ (un livre) →
  2. قَلَمٌ (un stylo) →
  3. طَالِبٌ (un étudiant) →
  4. بَيْتٌ (une maison) →
  5. رَجُلٌ (un homme) →
  6. بَابٌ (une porte) →
  7. وَلَدٌ (un garçon) →
  8. صَدِيقٌ (un ami) →

2Formation du duel : cas accusatif/génitif

Transformez les mots suivants au duel (cas direct/indirect)

Rappel : Ajoutez ـَيْنِ à la fin du mot

  1. كِتَابٌ (un livre) →
  2. قَلَمٌ (un stylo) →
  3. مُعَلِّمٌ (un enseignant) →
  4. طَبِيبٌ (un médecin) →
  5. كُرْسِيٌّ (une chaise) →
  6. شَهْرٌ (un mois) →

  2. سَيَّارَةٌ (une voiture) →

8Choisissez la bonne forme

Sélectionnez la forme correcte du duel selon le contexte

  1. جَاءَ ______ (وَلَدَانِ / وَلَدَيْنِ) → Deux garçons sont venus
  2. رَأَيْتُ ______ (كِتَابَانِ / كِتَابَيْنِ) → J'ai vu deux livres
  3. ______ (مُعَلِّمَانِ / مُعَلِّمَيْنِ) فِي الفَصْلِ → Deux enseignants dans la classe
  4. ذَهَبْتُ إِلَى ______ (مَدْرَسَتَانِ / مَدْرَسَتَيْنِ) → Je suis allé à deux écoles
  5. عِنْدِي ______ (قَلَمَانِ / قَلَمَيْنِ) → J'ai deux stylos
  6. تَكَلَّمْتُ مَعَ ______ (رَجُلاَنِ / رَجُلَيْنِ) → J'ai parlé avec deux hommes

11Trouvez l'erreur

Chaque forme contient une erreur. Corrigez-la :

  1. كِتَابُونَ (pour "deux livres") →
  2. مَدْرَسَةَانِ (pour "deux écoles") →
  3. طَالِبَاتَانِ (pour "deux étudiantes") →
  4. رَأَيْتُ رَجُلاَنِ (J'ai vu deux hommes) →
  5. صَحْرَاءَانِ (deux déserts) →

13Duel ou pluriel ?

Choisissez entre duel et pluriel selon le nombre

  1. Pour 2 livres, j'utilise : كِتَابَانِ ou كُتُبٌ ?
  2. Pour 3 étudiants, j'utilise : طَالِبَانِ ou طُلاَّبٌ ?
  3. Pour 2 voitures, j'utilise : سَيَّارَتَانِ ou سَيَّارَاتٌ ?
  4. Pour 5 hommes, j'utilise : رَجُلاَنِ ou رِجَالٌ ?
