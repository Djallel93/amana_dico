2Les trois types de verbes

Identifiez le type de chaque verbe (فَعَلَ / فَعِلَ / فَعُلَ) et donnez sa signification

  1. كَتَبَ → type : / sens :
  2. فَهِمَ → type : / sens :
  3. كَبُرَ → type : / sens :
  4. ذَهَبَ (aller) → type :
  5. سَمِعَ (entendre) → type :
  6. حَسُنَ (être bon) → type :
⚠️ Rappel : Le type فَعُلَ est rare et exprime presque toujours des qualités innées (être grand, être beau, être noble…).

9Vrai ou faux ?

Indiquez si les affirmations sont vraies (V) ou fausses (F)

  1. Au passé, on ajoute des préfixes à la racine
  2. La 3ᵉ pers. sg. masc. est la forme de base sans aucun suffixe
  3. Il y a une distinction de genre à la 1ʳᵉ personne
  4. La voyelle de la 2ᵉ radicale est toujours une fatḥa
  5. Les suffixes sont identiques pour les trois types فَعَلَ / فَعِلَ / فَعُلَ
  6. Le type فَعُلَ est le plus courant en arabe
  7. Le duel masculin et féminin de la 3ᵉ personne partagent le même suffixe ـَا
  8. Le suffixe ـْتُمَا correspond au duel de la 2ᵉ personne

10Trouvez l'erreur

Chaque forme verbale contient une erreur. Corrigez-la :

  1. كَتَبَتُ (je → 1ʳᵉ sg.) →
  2. فَهِمُوا avec voyelle i au milieu → s'écrit correctement :
  3. كَبُرْتَا (vous deux — duel 2ᵉ pers.) →
  4. كَتَبْنَ attribuée à « elles deux » (duel) →
  5. فَهِمَتُوا (elles → 3ᵉ pl. f.) →

11Exercice de compréhension

Lisez et répondez

كَتَبَ الطَّالِبُ دَرْسَهُ وَفَهِمَ الشَّرْحَ جَيِّدًا. كَتَبَتِ الطَّالِبَةُ أَيْضًا. كَبُرَ الوَلَدَانِ وَفَهِمَا أَهَمِّيَّةَ العِلْمِ. كَتَبْنَا مَعاً في الفَصْلِ.

Questions :

  1. Combien de formes verbales au passé y a-t-il dans ce texte ?
  2. Quelle est la personne/genre/nombre de كَتَبَ ?
  3. Quelle est la personne/genre/nombre de فَهِمَا ?
  4. Quel type est كَبُرَ ?
  5. Traduisez كَتَبْنَا مَعاً في الفَصْلِ :
