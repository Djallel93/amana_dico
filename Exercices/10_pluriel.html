📝 Exercices Pratiques

تَمَارِين الجَمْع
👋 Instructions : Complétez les exercices suivants pour pratiquer les formes du pluriel en arabe. Rappelez-vous : il existe deux types de pluriel — le pluriel régulier (الجَمْع السالِم) formé par suffixes, et le pluriel brisé (جَمْع التَّكسِير) à formation interne irrégulière.

1Pluriel masculin régulier : cas sujet

Ajoutez le suffixe ـُونَ (cas sujet) pour former le pluriel masculin régulier

  1. مُهَنْدِس (ingénieur) →
  2. مُعَلِّم (enseignant) →
  3. طالِب (étudiant) →
  4. مُدِير (directeur) →
  5. طَبِيب (médecin) →
  6. صَحْفِيّ (journaliste) →
  7. مُحَامٍ (avocat) →

2Pluriel masculin régulier : cas direct/indirect

Formez le pluriel masculin régulier au cas direct/indirect (ـِينَ)

  1. مُهَنْدِس →
  2. مُعَلِّم →
  3. طالِب →
  4. مُوَظَّف (employé) →
  5. كاتِب (écrivain) →
⚠️ Rappel : En phrase : رَأَيْتُ مُهَنْدِسِينَ (J'ai vu des ingénieurs) — cas direct donc ـِينَ.

3Pluriel féminin régulier

Formez le pluriel féminin régulier (ـاتٌ au nominatif)

Rappel : retirez le ة s'il y en a un, puis ajoutez ـاتٌ

  1. مَلِكَة (reine) →
  2. مُعَلِّمَة (enseignante) →
  3. طالِبَة (étudiante) →
  4. مُمَرِّضَة (infirmière) →
  5. جامِعَة (université) →
  6. سَيَّارَة (voiture) →

4Exceptions du pluriel féminin régulier

Donnez le pluriel de ces mots irréguliers

Ces pluriels doivent être mémorisés !

  3. أُمّ (mère) →
  4. أُخْت (sœur) →

8Doués de raison ou non ?

Classez ces mots : doués de raison (العاقِل) ou non doués de raison (غَيْر العاقِل)

Rappel : doués de raison = êtres humains ; non doués de raison = animaux, objets, concepts

  1. مُعَلِّم (enseignant) →
  2. كِتاب (livre) →
  3. حَيَوان (animal) →
  4. طالِبَة (étudiante) →
  5. شَجَرَة (arbre) →
  6. طَبِيب (médecin) →
  7. قَصِيدَة (poème) →
  8. بِنْت (fille) →

9Quel pluriel utiliser ?

Choisissez le pluriel correct selon la règle "doué de raison / non doué de raison"

  1. Pour مُعَلِّم (humain masculin), le pluriel est :
    a) مُعَلِّمُونَ   b) مَعالِم   →
  2. Pour طالِبَة (humain féminin), le pluriel est :
    a) طالِبات   b) طُلاّب   →
  3. Pour شَجَرَة (non humain), le pluriel est :
    a) شَجَرات (régulier)   b) أَشْجار (brisé) → les deux sont possibles, mais lequel est plus courant ?
  4. Pour حَيَوان (animal), le pluriel courant est :
    a) حَيَوانُونَ   b) حَيَوانات   →

11Vrai ou faux ?

Indiquez si les affirmations sont vraies (V) ou fausses (F)

  1. Le pluriel brisé modifie la structure interne du mot
  2. Le pluriel masculin régulier utilise les suffixes ـُونَ et ـِينَ
  3. Le pluriel régulier est plus fréquent que le pluriel brisé en arabe
  4. Les pluriels de noms non-humains s'accordent au féminin singulier
  5. On peut prédire le pluriel brisé depuis le singulier grâce à des règles absolues
  6. Le pluriel féminin régulier s'utilise parfois pour des objets inanimés
  7. Il est essentiel de mémoriser le pluriel en même temps que le singulier

12Trouvez l'erreur

Chaque forme de pluriel est incorrecte. Corrigez-la :

  2. كِتابُونَ comme pluriel de كِتاب →
  3. بَيْتات comme pluriel de بَيْت →
  4. أُمَّات comme pluriel de أُمّ →

💡 Conseil : Le pluriel brisé est la forme la plus fréquente en arabe. Lors de l'apprentissage d'un nouveau mot, mémorisez toujours le singulier ET le pluriel ensemble. Avec l'exposition à la langue, ces formes se mémoriseront naturellement !
🎯 Objectifs atteints : Après avoir complété ces exercices, vous devriez être capable de former les pluriels réguliers masculins et féminins, de reconnaître les pluriels brisés courants, et de choisir le bon type de pluriel selon la nature du nom (doué ou non doué de raison). 🎉
