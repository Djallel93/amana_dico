10Vrai ou faux ?

Indiquez si les affirmations sont vraies (V) ou fausses (F)

  1. Les pronoms relatifs arabes s'accordent en genre et en nombre avec l'antécédent
  2. Avec un antécédent indéfini, on doit utiliser الذِي ou التِي
  3. Pour un pluriel non-humain, on utilise toujours التِي
  4. Le revenant peut être implicite (sujet du verbe)
  5. مَنْ s'utilise pour les choses, ما pour les personnes
  6. مِمَّنْ est la contraction de مِنْ + مَنْ
  7. Dans une clause réduite, l'antécédent est présent mais non défini
  8. Le revenant n'est jamais obligatoire en arabe

11Trouvez l'erreur

Chaque phrase contient une erreur. Corrigez-la :

  1. الوَلَدُ التِي يَلْعَبُ (mauvais pronom pour masculin singulier) →
  2. الكُتُبُ الذِينَ قَرَأْتُها (mauvais pronom pour pluriel non-humain) →
  3. رَأَيْتُ طِفْلًا الذِي يَبْكِي (pronom relatif avec antécédent indéfini) →
  4. الطَّالِباتُ الذِينَ نَجَحُوا (mauvais pronom pour féminin pluriel humain) →
  5. ما يَصْبِرُ يَنْجَحُ (mauvais pronom générique pour une personne) →

💡 Conseils pour maîtriser les pronoms relatifs :
  • Mémorisez les trois formes de base : الذِي (m. sg.), التِي (f. sg. + pluriel non-humain), الذِينَ (m. pl. humain)
  • Entraînez-vous à identifier le revenant dans chaque phrase
  • Repérez les antécédents définis vs indéfinis dans vos lectures
  • N'oubliez jamais : التِي pour TOUT pluriel non-humain, même masculin !
