📝 Exercices Pratiques

تَمَارِين حُرُوف الجَرّ
👋 Instructions : Complétez les exercices suivants pour pratiquer les prépositions arabes. Règle fondamentale : toute préposition en arabe est suivie d'un nom au cas génitif (مَجْرُور), marqué par la kasra (ـِ) ou le tanwīn kasra (ـٍ). Attention aux prépositions monosyllabiques بِ، لِ، كَ qui s'attachent directement au mot.

1Les 8 prépositions essentielles

Associez chaque préposition à son sens principal

2Le cas génitif après les prépositions

Mettez le nom entre parenthèses au cas génitif

Rappel : défini → kasra ـِ ; indéfini → tanwīn kasra ـٍ

  1. ذَهَبْتُ إِلَى (المَدْرَسَة) →
  2. جَلَسْتُ فِي (حَدِيقَة) →
  3. تَحَدَّثْتُ مَعَ (الطُّلاّب) →
  4. جِئْتُ مِنَ (البَيْت) →
  5. كَتَبْتُ بِ (القَلَم) →
  6. هَذَا لِ (الطَّالِب) →
  7. هُوَ كَ (الأَسَد) →
  8. نَسِيتُ عَنْ (المَوْعِد) →

3Prépositions monosyllabiques attachées

Combinez la préposition avec le mot suivant

Rappel : بِ + ال = بِالـ / لِ + ال = لِلـ / كَ + ال = كَالـ

  1. بِ + القَلَم →
  2. لِ + الطَّالِب →
  3. كَ + الشَّمْس →
  4. بِ + كِتَاب →
  5. لِ + الطَّالِبَة →
  6. كَ + الأَسَد →

5Choisissez la bonne préposition

Choisissez parmi les prépositions proposées

  1. سَافَرْتُ ______ (مِنْ / إِلَى) بَارِيسَ → J'ai voyagé vers Paris
  2. أَسْكُنُ ______ (فِي / عَلَى) القَاهِرَةِ → J'habite au Caire
  3. الكِتَابُ ______ (فِي / عَلَى) الطَّاوِلَةِ → Le livre est sur la table
  4. تَحَدَّثَ ______ (عَنْ / مِنْ) السَّفَرِ → Il a parlé du voyage
  5. هَذَا الكِتَابُ ______ (لِ / بِ) المُعَلِّمِ → Ce livre est pour/au professeur
  6. كَتَبَ ______ (بِ / مِنْ) القَلَمِ → Il a écrit avec le stylo
  7. هُوَ ______ (كَ / عَنْ) الأَسَدِ شَجَاعَةً → Il est courageux comme un lion
  8. جِئْتُ ______ (مِنْ / إِلَى) المَدِينَةِ → Je suis venu de la ville

6Traduisez en arabe

Traduisez les phrases en veillant à l'accord en génitif

  1. Je suis allé(e) à l'école →
  2. Je suis venu(e) de France →
  3. J'ai écrit avec le stylo sur la feuille →

  5. Il est comme un lion →

8Prépositions de lieu détaillées

Complétez avec la bonne préposition de lieu

Utilisez : أَمَامَ / خَلْفَ / فَوْقَ / تَحْتَ / بَيْنَ / عِنْدَ

  1. وَقَفْتُ ______ البَابِ → Je me suis tenu(e) devant la porte
  2. الحَدِيقَةُ ______ المَنْزِلِ → Le jardin est derrière la maison
  3. الطَّائِرُ ______ الشَّجَرَةِ → L'oiseau est au-dessus de l'arbre
  4. القِطُّ ______ الطَّاوِلَةِ → Le chat est sous la table
  5. جَلَسْتُ ______ أَحْمَدَ وَفَاطِمَةَ → Je me suis assis(e) entre Ahmad et Fatima
  6. أَنَا ______ صَدِيقِي → Je suis chez mon ami

9Dialogue : Directions

Complétez le dialogue avec les prépositions correctes

A : أَيْنَ المَسْجِدُ ______؟ (s'il vous plaît)

B : المَسْجِدُ ______ المَدْرَسَةِ وَالسُّوقِ (entre l'école et le marché)

A : كَيْفَ أَذْهَبُ ______ هِ؟ (vers lui)

B : اِمْشِ ______ الأَمَامِ (vers l'avant)، ثُمَّ اِنْعَطِفْ ______ اليَمِينِ (à droite)

10Vrai ou faux ?

Indiquez si les affirmations sont vraies (V) ou fausses (F)

  1. Toute préposition impose le cas génitif au nom qui suit
  2. Les prépositions بِ، لِ، كَ peuvent s'écrire séparément du mot qui suit
  3. La préposition عَلَى peut exprimer une obligation
  4. مِنْ + مِنْ = مِمَّنْ quand on la combine avec مَنْ
  5. La préposition فِي ne s'utilise que pour les lieux
  6. Quand لِ précède l'article ال, on dit لِلـ
  7. عَنْ s'utilise uniquement pour exprimer l'éloignement

11Trouvez l'erreur

Corrigez les erreurs dans les phrases suivantes

  1. ذَهَبْتُ إِلَى المَدْرَسَةُ (nominatif après préposition) →
  2. كَتَبْتُ ب القَلَمِ (préposition séparée) →
  3. هَذَا الكِتَابُ لِ أَحْمَدَ (préposition séparée) →
  4. جِئْتُ مِنِّي (pronom de 1ère personne incorrect) →
  5. تَحَدَّثَ فِي السَّفَرِ (mauvaise préposition pour parler "de" quelque chose) →

12Phrases récapitulatives

Traduisez ces phrases complexes contenant plusieurs prépositions

  1. J'ai voyagé de Paris au Caire →
  2. Il s'est assis entre Ahmad et Ali devant le professeur →
  3. Ce livre est à moi, et celui-là est à toi →
  4. Tu dois étudier → (avec عَلَى)
💡 Conseil : Pour bien maîtriser les prépositions, pratiquez-les dans des phrases complètes et mémorisez les expressions courantes. Les prépositions sont souvent idiomatiques : leur usage précis s'apprend par la pratique et la lecture régulières.
🎯 Objectifs atteints : Après avoir complété ces exercices, vous devriez être capable d'identifier les prépositions arabes, de mettre le nom qui suit au génitif, d'attacher les prépositions monosyllabiques et de combiner les prépositions avec les pronoms suffixes. Bravo ! 🎉
