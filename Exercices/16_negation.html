Exercices : La négation

النَّفْي
Trois particules, trois temps : ما pour nier le passé, لا pour nier le présent, et لَنْ pour nier le futur. Ces exercices reprennent كَتَبَ (écrire) et فَهِمَ (comprendre), déjà bien connus, pour fixer les trois structures.

1Nier le passé — ما + ماضي

Mettez chaque phrase à la forme négative avec ما

  1. كَتَبَ الوَلَدُ الدَّرْسَ →
  2. فَهِمْتُ السُّؤَالَ →
  3. كَتَبْنَا رِسَالَةً →
  4. فَهِمَتِ البِنْتُ الدَّرْسَ →
  5. كَتَبَ الطُّلَابُ الوَاجِبَ →

2Nier le présent — لا + مضارع

Mettez chaque phrase à la forme négative avec لا

  1. يَكْتُبُ الوَلَدُ رِسَالَةً →
  2. أَفْهَمُ الدَّرْسَ →
  3. تَكْتُبِينَ جَيِّدًا →
  4. نَفْهَمُ اللُّغَةَ العَرَبِيَّةَ →
  5. تَفْهَمُونَ السُّؤَالَ →

3Nier le futur — لَنْ + مضارع

Transformez chaque futur affirmatif en futur nié avec لَنْ (attention à la terminaison)

  1. سَيَكْتُبُ الوَلَدُ →
  2. سَأَفْهَمُ الدَّرْسَ →
  3. سَوْفَ نَفْهَمُ →
  4. سَتَكْتُبُونَ الوَاجِبَ →
⚠️ Rappel : Après لَنْ, la ḍamma finale devient une fatḥa, et le نَ final des formes en ـُونَ / ـِينَ disparaît.

4Quelle particule choisir ?

Complétez chaque phrase avec ما, لا ou لَنْ selon le contexte

  1. فَهِمْتُ هَذَا الكِتَابَ أَمْسِ (hier, donc passé)
  2. أَذْهَبُ إِلَى المَدْرَسَةِ غَدًا (demain, donc futur)
  3. يَفْهَمُ الوَلَدُ الدَّرْسَ الآنَ (maintenant, donc présent)
  4. كَتَبَتِ البِنْتُ رِسَالَةً البَارِحَةَ (hier soir, donc passé)

5لا de négation ou لا de prohibition ?

Pour chaque phrase, indiquez s'il s'agit d'un constat (négation) ou d'un ordre (prohibition)

  1. لا يَكْتُبُ →
  2. لا تَكْتُبْ →
  3. لا تَفْهَمِينَ →
  4. لا تَفْهَمِي →

6Tableau récapitulatif — فَهِمَ / يَفْهَمُ

Complétez le tableau des trois négations pour le verbe فَهِمَ / يَفْهَمُ (comprendre)

Personne ما + passé لا + présent لَنْ + présent

7Trouvez l'erreur

Chaque phrase contient une erreur de négation. Corrigez-la

  1. لَنْ يَكْتُبُ الوَلَدُ (après لَنْ, pas de ḍamma finale) →
  2. ما يَكْتُبُ الوَلَدُ أَمْسِ (ما se combine avec le passé, pas le présent) →
  3. لا كَتَبَ الوَلَدُ (لا se combine avec le présent, pas le passé) →
  4. لَنْ تَكْتُبُونَ الوَاجِبَ (le نَ final doit disparaître) →

8Traduisez en arabe

Choisissez la bonne particule de négation selon le temps indiqué

  1. Ahmed n'est pas allé à l'école (passé) →
  2. Je ne comprends pas ce livre (présent) →
  3. Le garçon n'écrira pas le devoir (futur) →
  4. Nous n'avons pas compris la leçon hier (passé) →

9Exercice de compréhension

Lisez et répondez

ما فَهِمَ الوَلَدُ الدَّرْسَ أَمْسِ، وَلا يَفْهَمُهُ الآنَ أَيْضًا. لَنْ يَنْجَحَ فِي الاِمْتِحَانِ إِذَا لَمْ يَدْرُسْ. قَالَتِ الأُسْتَاذَةُ: لا تَقْلَقْ، سَأُسَاعِدُكَ.

Questions :

  1. Combien de négations au passé (ما) trouve-t-on dans ce texte ?
  2. Quelle négation porte sur le futur ? Que signifie-t-elle ?
  3. لا تَقْلَقْ est-elle une négation ou une prohibition ?
  4. Traduisez لا يَفْهَمُهُ الآنَ أَيْضًا :
🎯 Objectifs atteints : Après avoir complété ces exercices, vous devriez savoir choisir la bonne particule de négation selon le temps de la phrase (ما، لا، لَنْ), et repérer la petite transformation qu'entraîne لَنْ sur la terminaison du verbe. Excellent travail ! 🎉
