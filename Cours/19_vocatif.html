Le vocatif en arabe

النِداء
Le vocatif (النِداء) est l'acte d'appeler ou d'interpeller quelqu'un directement. Contrairement au français où on se contente souvent du prénom, l'arabe utilise des particules vocatives spécifiques placées avant le nom de la personne appelée. C'est une structure très présente dans la langue quotidienne, dans la littérature et dans le Coran. La structure est simple : particule + nom appelé (المُنادى).

📋 Les particules vocatives — أَدَوات النِداء

Il existe plusieurs particules vocatives en arabe, toutes traduisibles par « Ô / Hé ». Trois d'entre elles sont régulièrement utilisées selon le contexte :

La plus courante

يَا

Utilisée pour appeler sans article défini

Prénoms, noms communs, professions…

يا + nom sans الـ

Pour les hommes (défini)

أَيُّها

Utilisée quand le nom qui suit porte l'article الـ

Masculin — singulier, duel, pluriel

أَيُّها + الـ + nom masc.

Pour les femmes (défini)

أَيَّتُها

Utilisée quand le nom qui suit porte l'article الـ

Féminin — singulier, duel, pluriel

أَيَّتُها + الـ + nom fém.
⚙️ Règle de base :
  • Le nom appelé n'a pas l'article الـ → on utilise يَا
  • Le nom appelé a l'article الـ + masculin → on utilise أَيُّها
  • Le nom appelé a l'article الـ + féminin → on utilise أَيَّتُها
📣 Partie 1

📣 La particule يَا — usages et exemples

يَا est de loin la particule la plus fréquente. Elle s'utilise dans trois grandes situations : l'appel direct, le cri de détresse, et la lamentation.

👤 1. L'appel direct — النِداء العادي

La fonction principale : attirer l'attention de quelqu'un.

يَا مُحَمَّدُ !
Ô Mohamed ! / Hé Mohamed !
Prénom propre → يا + cas sujet sans tanwīn (ضمة)
يَا أُسْتَاذُ، أَعْرِفُ الجَوَابَ !
Professeur ! Je connais la réponse !
Nom commun singulier bien déterminé → cas sujet sans tanwīn
يَا أَمِينَةُ، أَيْنَ أَنْتِ ؟
Amina, où es-tu ?
Prénom féminin → cas sujet sans tanwīn

🆘 2. L'appel de détresse — الاِسْتِغاثة

يَا قَوْمِي !
Ô mon peuple ! (aidez-moi !)
Appel collectif de détresse — suffixe pronominal ي

😢 3. La lamentation — النَدْبة

يَا حَسْرَةً عَلَى العِبَادِ !
Quel regret pour les serviteurs ! (Coran, Yā-Sīn : 30)
Emploi littéraire et coranique — exprime la douleur ou le regret
⚖️ Partie 2

⚖️ Le cas du nom appelé — إِعراب المُنادى

Le nom appelé (المُنادى) après يَا peut être au cas sujet ou au cas direct selon le type de nom. C'est la règle la plus importante du vocatif !

✅ Cas sujet (مَرْفُوع) sans tanwīn

  • Nom propre simple
    يَا عَلِيُّ
  • Nom commun singulier bien identifié
    يَا أُسْتَاذُ

✅ Cas direct (مَنْصُوب)

  • Entité vague / indéfinie
    يَا زَعِيمًا كُنْ عادِلاً
  • Nom suivi d'une annexion (إضافة)
    يَا رَئِيسَ الوُزَرَاءِ
  • Prénom composé (عَبْد + الـ)
    يَا عَبْدَ الكَرِيمِ

📝 Exemples avec annexion (إضافة) — cas direct

يَا رَئِيسَ الوُزَرَاءِ !
Ô Premier ministre !
Annexion → cas direct (فتحة sur رَئِيسَ)
يَا عَبْدَ الكَرِيمِ !
Ô Abdelkarim !
Prénom composé عبد + الكريم → cas direct
يَا طَالِبًا كُنْ مُجْتَهِدًا !
Ô étudiant (en général), sois appliqué !
Destinataire vague (n'importe quel étudiant) → cas direct + tanwīn
📌 يَا + suffixe pronom ي : Quand le nom appelé est suivi du pronom personnel suffixe ي (mon/ma), la dernière voyelle s'allège souvent :
يَا رَبِّي → يَا رَبِّ (Ô mon Seigneur !)
🎙️ Partie 3

🎙️ Les particules أَيُّها et أَيَّتُها

Ces deux particules s'utilisent exclusivement avec des noms portant l'article الـ. Elles sont typiques des discours formels, des sermons, des allocutions et du style coranique. Le nom qui les suit est toujours au cas sujet (مَرْفُوع).

📝 Exemples de discours formels

أَيُّها المُوَاطِنُونَ !
Chers citoyens ! / Ô citoyens !
Masculin pluriel → أَيُّها + المواطنون (cas sujet)
أَيَّتُها السَّيِّدَاتُ !
Mesdames !
Féminin pluriel → أَيَّتُها + السيدات (cas sujet)
أَيُّها المُدِيرُ، لَدَيَّ سُؤَالٌ !
Monsieur le directeur, j'ai une question !
Masculin singulier avec الـ → أَيُّها

📖 يَا + أَيُّها — la formule coranique

La combinaison يَا أَيُّها ajoute encore plus de solennité. C'est la formule utilisée dans le Coran pour s'adresser aux croyants :

يَا أَيُّها الَّذِينَ آمَنُوا
Ô vous qui avez cru ! (formule coranique récurrente)
🕌 Cas particulier : s'adresser à Dieu

Pour s'adresser à Dieu, on peut utiliser la construction normale يَا إِلَهِي, mais il existe une forme spéciale sans particule vocative, largement utilisée dans le Coran :

اللّهُمَّ = يَا إِلَهِي
« Ô Dieu ! » — le suffixe مَّ remplace la particule يَا.
📎 Partie 4

📎 Le nom qui suit le destinataire

Parfois, le nom appelé (المُنادى) est suivi d'un adjectif, d'un deuxième nom ou d'une conjonction. Voici les règles pour ces cas :
CasRègleExempleTraduction
Destinataire indéclinable (démonstratif, pronom) Le nom qui suit est au cas sujet يَا هَذَا الحَارِسُ Ô ce gardien !
Adjectif non premier terme d'annexion Cas direct ou cas sujet يَا سُفْيَانُ الشَّرِيفُ Ô honorable Sofiane !
Deux noms reliés par وَ Le deuxième suit le premier يَا سَمِيرُ وَمُحْسِنُ Ô Samir et Mohsin !

📝 Résumé de la leçon

  • Le vocatif = particule + nom appelé (المُنادى)
  • يَا s'utilise avec les noms sans article الـ (prénoms, noms communs, entités vagues, annexions)
  • أَيُّها (masc.) et أَيَّتُها (fém.) s'utilisent avec les noms portant الـ
  • Le nom appelé est au cas sujet sans tanwīn si c'est un nom propre ou commun bien identifié
  • Le nom appelé est au cas direct si c'est une entité vague ou en annexion
  • Après أَيُّها / أَيَّتُها, le nom est toujours au cas sujet
  • اللّهُمَّ = يَا إِلَهِي — formule spéciale pour s'adresser à Dieu
